
# Clay → HubSpot Sales Handoff Rules

## 1. Qualification
A company is eligible for handoff only when:
- ICP score is 70 or higher
- Research QA = Pass
- Human approval = Yes

## 2. Duplicate Prevention
- Search HubSpot using the company's primary domain.
- If the company exists, review the existing record.
- If the company does not exist, create a new record after approval.
- Never overwrite existing data without checking it.

## 3. Lead Routing
- US B2B SaaS, 50–200 employees → SMB SDR
- US B2B SaaS, 201–500 employees → Mid-Market SDR
- Missing or conflicting data → Manual Review

## 4. Follow-up
After a qualified company is assigned:
- Create a follow-up task.
- Set the due date to the next business day.
- Record the qualification reason.
- Track whether the SDR accepts the handoff.

## 5. Success Metrics
- Percentage of approved companies assigned an owner
- Number of duplicate records prevented
- Time from approval to assignment
- Percentage of follow-up tasks completed on time
