
# Quivly – Customer Onboarding Engine

## Overview

A Python-based customer onboarding automation tool
that tracks implementation milestones, calculates
onboarding progress, and classifies customer health
across multiple SaaS accounts.

## Features

- JSON-based customer data processing
- Automated onboarding progress calculation
- Multi-customer portfolio processing
- Rule-based customer health classification
- Reusable Python functions
- Division-by-zero prevention
- Edge-case testing

## Sample Results

| Customer | Progress | Health Status |
|---|---|---|
| Acme Technologies | 75% | On track |
| Nova Health | 50% | Needs attention |
| Orbit AI | 100% | Fully onboarded |

## Technology Stack

- Python
- JSON
- Git and GitHub
- Cursor IDE

## How to Run

Run the following command from the project directory:

`python3 portfolio_engine.py`

No external Python libraries are required.
